# Карточки English

Карточки для слов: спереди русское слово, на обороте английское. На английской стороне кнопка «Транскрипция» показывает транскрипцию и русское чтение.

Приложение: https://kesklinn.github.io/kartochki/ - в Chrome на Android меню ⋮ → «Установить приложение». Работает без интернета.

## Слова

Слова берутся из Google-таблицы «Карточки NNN - слова» (доступ по ссылке - читатель).

| Русский | Английский | Транскрипция | Чтение | Список |
|---|---|---|---|---|
| очередь | queue | /kjuː/ | «кью» | NNN |

- Транскрипцию и чтение можно не заполнять - тогда кнопки «Транскрипция» на карточке нет.
- «Список» - одно или несколько названий через запятую. Пусто - слово только во «Все слова».
- Без интернета приложение работает с последним загруженным списком.

## Устройство

- `src/` - исходники: `deck.js` (логика колоды), `sheet.js` (чтение таблицы), `lists.js` (списки), `ui.js` (интерфейс), `cards.js` (встроенные слова на случай первого запуска без сети).
- `docs/` - собранное приложение, его отдает GitHub Pages. Не править руками: `npm run build`.
- `test/` - автотесты: `npm test`.
